۱. انتخاب پروژه

هنوز فایلی انتخاب نشده است.

۲. پیش‌نمایش برنامه

پیش‌نمایش داخل همین صفحه نمایش داده می‌شود. برخی قابلیت‌های وابسته به سرور ممکن است در پیش‌نمایش محلی کار نکنند.

۳. گرفتن APK

  1. روی «ساخت و دانلود بسته Android» بزن.
  2. ZIP خروجی را در یک مخزن GitHub بارگذاری کن.
  3. از تب Actions اجرای workflow را دنبال کن.
  4. پس از پایان موفق، APK را از بخش Artifacts دانلود کن.

این ابزار به‌تنهایی APK را روی گوشی کامپایل نمی‌کند؛ بسته پروژه و workflow ساخت را آماده می‌کند. برای ساخت APK به GitHub Actions نیاز است.
