# APK Editor

سازنده بسته اندروید از پروژه‌های وب؛ رابط کاربری فارسی و سازگار با موبایل.

## امکانات
- انتخاب فایل HTML یا ZIP
- پیش‌نمایش HTML
- تعیین نام و شناسه پکیج اندروید
- ساخت ZIP پروژه Capacitor به همراه GitHub Actions workflow
- ساخت APK آزمایشی (debug) روی GitHub Actions و دریافت آن از Artifacts

## انتشار سایت با GitHub Pages
1. در مخزن به Settings → Pages بروید.
2. در بخش Build and deployment، گزینه **GitHub Actions** را به عنوان Source انتخاب کنید.
3. در تب Actions، اجرای Deploy APK Editor را بررسی کنید.
4. پس از موفقیت، سایت در آدرس https://pioneer8254-afk.github.io/Apkeditor/ در دسترس است.

## ساخت APK از پروژه خودتان
1. فایل HTML یا ZIP را در سایت انتخاب کنید.
2. نام برنامه و شناسه یکتای پکیج را وارد کنید (مثل `com.example.myapp`).
3. پیش‌نمایش را بررسی و روی «ساخت و دانلود بسته Android» بزنید.
4. یک مخزن GitHub جدید بسازید و تمام فایل‌های داخل ZIP خروجی را در شاخه `main` آن بارگذاری کنید.
5. در تب Actions، workflow با نام **Build Android APK** را اجرا کنید.
6. پس از موفقیت، در همان اجرای workflow بخش Artifacts را باز و `app-debug` را دانلود کنید.
7. فایل APK داخل ZIP دانلودی قرار دارد.

## محدودیت نسخه
این نسخه APK امضاشده برای انتشار در Google Play تولید نمی‌کند؛ خروجی فعلی APK آزمایشی (debug) است. برای انتشار عمومی باید کلید امضای خصوصی و تنظیمات release امن اضافه شود. پروژه‌های وبی که به backend یا دامنه خارجی وابسته‌اند، برای کارکرد کامل به اینترنت نیاز دارند.
